# E-Waste ATM ♻️

## About the Project
E-Waste ATM is a web-based e-waste management and reward system developed as part of a college Ideathon event.

The project encourages responsible electronic waste disposal by allowing users to deposit e-waste, earn reward points, and redeem eco-friendly rewards.

It also includes an admin approval system where submitted responses are reviewed and accepted or declined through a spreadsheet.

## Key Features

### 1. Deposit
- Users can submit their e-waste deposit details through the website.
- Submitted responses are recorded in a spreadsheet.
- Admins can accept or decline deposit requests.

### 2. Wallet
- Users receive reward points for approved deposits.
- Points are displayed in the user's wallet.
- Users can track their available points.

### 3. Redeem
Users can redeem their accumulated points for rewards.

| Reward | Points |
|---|---:|
| Eco-friendly Bookmark | 20 |
| Pen or Pencil Set | 40 |
| Sustainability Certificate | 50 |

*The reward catalogue and point allocation system can be modified in the future.*

## Admin Workflow
1. User submits an e-waste deposit request.
2. The response is recorded in the spreadsheet.
3. Admin reviews the submitted request.
4. Admin accepts or declines the request.
5. Approved requests receive reward points in the wallet.

## Technologies Used
- HTML – Website structure
- JavaScript – Functionality and interactions
- Spreadsheet – Response tracking and admin approval workflow

## Project Purpose
To encourage e-waste recycling, promote environmental awareness, and motivate responsible disposal of electronic waste through a reward-based system.
